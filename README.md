# B站视频总结拓展

在 B 站视频页一键抓取字幕、弹幕与评论，并自动将整理好的 prompt 发送到 Gemini 网页版小窗（走账号网页额度），总结结果直接在小窗中查看；同时在 B 站动态页的视频卡片左侧显示 B 站官方 AI 总结。

> 这是一个浏览器扩展（Chrome Extension Manifest V3），所有内容均在本地处理，不经过第三方服务器。

## 功能特性

- **视频页一键总结**：在任意 B 站视频页面左下角出现悬浮按钮，点击后自动抓取字幕/弹幕/评论并发送到 Gemini。
- **多维度分析**：可勾选结论要点、精华详解、时间戳、弹幕分析、评论区、推广/立场、信息验证、标题党鉴定、思维导图等模块。
- **动态页官方总结**：在 B 站动态（t.bilibili.com）视频卡片左侧直接展示 B 站官方 AI 总结。
- **多 AI 提供商支持**（配置中可选）：Gemini、ChatGPT、Grok、Claude、DeepSeek、GLM、Kimi 等。
- **思维导图**：支持将总结结果一键生成可交互的思维导图（markmap）。
- **本地处理**：字幕优先通过页面内钩子拦截，不会上传视频本身，仅将文本 prompt 发送到用户已登录的 AI 网页版。

## 安装说明

### 方式一：开发者模式加载（推荐，无需商店审核）

1. 下载或克隆本仓库到本地任意目录。
2. 打开 Chrome / Edge / 其他 Chromium 内核浏览器，进入扩展管理页面：
   - Chrome：`chrome://extensions/`
   - Edge：`edge://extensions/`
3. 打开右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」。
5. 选择本仓库根目录（包含 `manifest.json` 的文件夹）。
6. 扩展图标会出现在浏览器工具栏，点击图标可进入设置弹窗。

### 方式二：打包安装

1. 进入扩展管理页面的「开发者模式」。
2. 点击「打包扩展程序」，选择本仓库根目录。
3. 将生成的 `.crx` 文件拖入扩展管理页面即可安装（部分浏览器需开启允许拖拽安装）。

## 使用方法

1. **视频页总结**
   - 打开任意 B 站视频页面（`https://www.bilibili.com/video/...`）。
   - 点击左下角悬浮的「🧐 总结到 Gemini」按钮。
   - 扩展会自动打开 Gemini 网页版小窗，并将整理好的 prompt 填入发送框。
   - 在 Gemini 小窗中查看总结结果。

2. **动态页官方总结**
   - 打开 B 站动态页（`https://t.bilibili.com`）。
   - 视频卡片左侧会自动显示 B 站官方 AI 总结（可在弹窗设置中开关）。

3. **设置**
   - 点击浏览器工具栏的扩展图标，可设置：
     - 是否启用动态页官方总结
     - 是否启用视频页快速总结
     - 是否每次新建对话
     - 固定模型与默认 AI 提供商
